# IoMTTVRAAnalysis

These files are the input and result analysis of a feedback loop workflow for threat modeling and analysis. The files are:

- **iomt_model.json**: the input model created.
- **threats.json**: the list of 1.546 threats returned from the threat analysis report.
- **recommendations.json**: the list of recommendations
- **tvra_attack_path_graph.png**: the identified attack paths.
- **Exported_Report_2025-10-17_12_02_33.htm**: a detailed report with risk treatment plan, with any kind of risk level.
- **iomt_tool_screenshot.png**: a screenshot of the modeling tool with the produced model.
